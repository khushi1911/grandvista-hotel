# GrandVista Hotel

A responsive hotel website designed to provide a smooth and elegant hotel browsing and booking experience. The project includes hotel information, rooms, dining, amenities, events, gallery, offers, reviews, FAQs, contact information, and an interactive booking flow.

## Live Website

Coming soon — GitHub Pages deployment will be added after final deployment.

## Project Overview

GrandVista Hotel is a frontend-based hotel website developed using HTML, CSS, and JavaScript. The website focuses on responsive design, clear navigation, interactive components, form validation, and a polished user experience across desktop, tablet, and mobile devices.

## Features

- Responsive hotel website
- Modern and professional hotel UI
- Homepage with hotel highlights and booking widget
- Room listing and room details
- Room pricing information
- Booking form with validation
- Booking confirmation page
- Dining and restaurant information
- Interactive dining menu filters
- Hotel amenities and facilities
- Events and celebrations section
- Gallery with filtering
- Special offers
- Guest reviews
- FAQ section
- Nearby attractions
- Hotel location information
- Contact page
- Privacy Policy, Terms & Conditions, and hotel policies
- Responsive navigation and layouts
- JavaScript-based interactions and validation

## Key Functionality

### Room Browsing

Users can browse available room categories, view room details, pricing, amenities, and proceed to the booking page.

### Booking

The booking section provides a structured reservation form with client-side validation and a confirmation flow.

### Dining

The dining page presents the hotel's dining venues, cuisine options, menu items, prices, and interactive menu category filters.

### Gallery

The gallery provides categorized hotel images with interactive filtering for easier browsing.

### Events

Users can explore event and celebration options offered by GrandVista Hotel.

### Responsive Design

The website is designed to adapt to different screen sizes including:

- Desktop
- Laptop
- Tablet
- Mobile

## Running Locally

No backend or database setup is required.

### 1. Clone the Repository

    git clone https://github.com/khushi1911/grandvista-hotel.git

### 2. Open the Project

Open the project folder in VS Code.

### 3. Run the Website

Open `index.html` in a browser, or use the VS Code Live Server extension.

The website runs entirely on the frontend.
